BI-Monday V25.17 — Reunião NQ / Operação e Qualidade

ALTERAÇÃO PRINCIPAL
- A fonte oficial para os critérios de não conformidade passa a ser a coluna “Apontamos inconformidade?” do Monday.
- “Sim” = Não conforme.
- “Não” = Conforme.
- Em branco/outro valor = não entra no cálculo.

OUTROS AJUSTES

- A view de detalhe é lida com todos os campos para localizar automaticamente o alias de “Apontamos inconformidade?”.
- Há fallback para `dados_colunas` quando a view traz o JSON completo das colunas do Monday.

DIAGNÓSTICO
