V23.3 — UMA LINHA POR PROFESSOR

Esta versão NÃO exige novo SQL e NÃO exige alteração na Edge Function.

Para instalar:
1. Substitua os arquivos do BI no GitHub pela V23.3.
2. Aguarde o GitHub Pages.
3. Pressione Ctrl+F5.
4. Abra Reunião NQ > Formação e cobertura dos especialistas.

Alterações:
- Área de formação por especialista:
  cada professor aparece uma única vez.
- Lista de formações e professores:
  cada professor aparece uma única vez.
- As múltiplas formações são mostradas na mesma linha.
- Áreas CINE repetidas são removidas.
