# BI-Monday V25.28

Correção de timeout da sincronização Monday e do SQL da página Operação.

## Mudanças principais
- `sync-monday` processa apenas 1 página do Monday por execução (até 500 itens).
- O cursor fica salvo em `monday_sync_state`; a próxima execução continua de onde parou.
- Registros antigos só são removidos quando o ciclo inteiro termina.
- A view `vw_operacao_materiais_completa` foi reescrita sem `to_jsonb(... )::text`, que causava consultas muito pesadas.
- Os diagnósticos de Contabilidade foram separados do SQL de instalação.

## Ordem de atualização
1. Deploy de `supabase/functions/sync-monday/index.ts`.
2. Executar `docs/V25_28_01_INSTALAR_SYNC_E_VIEW_OTIMIZADA.sql`.
3. Executar `docs/V25_28_02_CRON_PAGINADO.sql`.
4. Testar `{"acao":"sincronizar-esteira"}` algumas vezes. Cada chamada avança uma página.
5. Quando `ciclo_concluido` vier `true`, executar `docs/V25_28_03_DIAGNOSTICO_CONTABILIDADE.sql`.
6. Publicar os arquivos do site no GitHub e usar Ctrl+F5.
