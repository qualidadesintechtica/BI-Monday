V24.11 — CORREÇÃO DO BOTÃO IMPORTAR NOVA PLANILHA

CAUSA
A V24.6 tinha uma regra:
#projeto-qualidade -> projetos.html

O botão "Importar nova planilha" também apontava para:
index.html#projeto-qualidade

Assim, ao clicar, a própria regra de redirect mandava o usuário
de volta para projetos.html. Parecia que o botão não funcionava.

CORREÇÃO
O botão agora abre:
index.html?abrir_importacao_pq=1#projeto-qualidade

O index reconhece esse parâmetro e NÃO executa o redirect.

PASSOS
1. Substitua no GitHub principalmente:
   - index.html
   - projetos.html
   - js/config.js
2. Aguarde o GitHub Pages.
3. Ctrl+F5.
4. Abra projetos.html.
5. Clique em "Importar nova planilha".
6. Deve abrir a área de importação do Projeto Qualidade.
