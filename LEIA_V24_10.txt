V24.10 — DATAS DO PROJETO QUALIDADE

CAUSA ENCONTRADA
A planilha não guarda várias datas como texto.
Ela usa números seriais do Excel, como 46090, 46269, 46329 etc.

A versão anterior dependia da conversão do navegador.
Agora a conversão é feita em três níveis:
1. importador do navegador;
2. Edge Function;
3. tela do Projeto Qualidade, com fallback de dados_origem.

Além disso existe um SQL que corrige os registros JÁ IMPORTADOS.

ORDEM
1. Supabase > SQL Editor:
   execute docs/V24_10_CORRIGIR_DATAS_EXISTENTES.sql inteiro.

2. Supabase > Edge Functions > import-projeto-qualidade:
   substitua TODO o código por
   supabase/functions/import-projeto-qualidade/index.ts
   e faça Deploy.

3. GitHub:
   substitua pelos arquivos desta V24.10.

4. Aguarde o GitHub Pages e pressione Ctrl+F5.

5. Abra Projeto Qualidade.
   As datas devem aparecer como DD/MM/AAAA.

6. Nas próximas planilhas, a importação já converterá as datas automaticamente.
