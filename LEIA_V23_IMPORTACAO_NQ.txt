BI MONDAY V23 — IMPORTAÇÃO RECORRENTE DA BASE NQ

OBJETIVO
Permitir que uma pessoa autenticada no BI selecione a planilha atualizada de
especialistas e envie os dados para o Supabase sem cadastro manual.

FLUXO
Excel (.xlsx/.xls)
  -> página Reunião NQ
  -> Edge Function import-nq-especialistas
  -> validação da aba "Export"
  -> nq_especialistas
  -> nq_especialistas_formacoes
  -> nq_importacoes (histórico)

COMPORTAMENTO NA ATUALIZAÇÃO
- O mesmo professor é localizado primeiro pelo CPF normalizado e depois pelo nome.
- Dados existentes são atualizados.
- Novos professores são inseridos.
- As formações do professor são recriadas conforme a planilha mais recente.
- Professores ausentes da nova planilha ficam como ativo=false.
- Nenhum professor é apagado.
- Cada envio fica registrado em nq_importacoes.

INSTALAÇÃO
1. Supabase -> SQL Editor:
   execute o arquivo docs/V23_01_PREPARAR_IMPORTACAO_NQ.sql INTEIRO.

2. Supabase -> Edge Functions:
   crie a função: import-nq-especialistas
   substitua o conteúdo pelo arquivo:
   supabase/functions/import-nq-especialistas/index.ts
   faça o Deploy.

3. GitHub:
   substitua os arquivos do BI pelos arquivos desta V23.
   Aguarde o GitHub Pages concluir o deploy.
   Pressione Ctrl+F5.

4. Teste:
   Reunião NQ -> seção 06 Base de especialistas
   -> Selecionar planilha
   -> Enviar para o banco.

PLANILHA ESPERADA
Aba: Export
Colunas obrigatórias:
- PROFESSOR INDICADO PARA CONTRATAÇÃO
- FORMAÇÃO

As demais colunas do arquivo "01. Profs TIs - NQ.xlsx" também são lidas quando existirem.

SEGURANÇA
O navegador não recebe a service_role key.
A gravação é feita dentro da Edge Function autenticada.
CPF e telefone não são necessários para as telas do relatório e a V23 revoga
SELECT direto da tabela nq_especialistas para authenticated.
